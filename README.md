# webpro_06

Webプログラミングの演習用リポジトリ。

## week9：データの詳細表示

`webpro_06`ディレクトリで、以下を実行する。

```sh
npm install
node app5.js
```

- 駅一覧：<http://localhost:8080/keiyo2>
- 駅詳細の例：<http://localhost:8080/keiyo2/0>
- 駅追加フォーム：<http://localhost:8080/keiyo2/create>

データは変数内に保存するため、再起動すると初期状態に戻る。
`npm start`は`app4.js`を起動するので、この演習では`node app5.js`を使用する。

## week10：POSTによる新規登録・編集・更新

駅一覧の「駅を追加する」からフォームを開き、駅情報を登録する。
フォームは`POST /keiyo2`へ送信し、サーバは`req.body`から入力値を受け取る。
IDはサーバが自動で割り当て、登録後は駅一覧へ戻る。
乗り換え線は空欄でも登録でき、乗降客数と距離には0以上の値を指定する。

駅の詳細ページで「編集」を選ぶと、現在の値を入力済みの編集フォームが開く。
「更新」は`POST /keiyo2/update/:number`へ送信し、変更を保存して駅一覧へ戻る。
IDは編集せず、駅コード・駅名・乗り換え線・乗降客数・距離を変更できる。
URLの`:number`は配列の位置（0始まり）であり、表示するIDとは異なる。
